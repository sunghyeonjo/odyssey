# 앱 심사 제출 노트

App Store Connect 의 **심사 정보(App Review Information)** 에 그대로 옮겨 적는 내용.

## 시연 계정

| | |
|---|---|
| 이메일 | `demo@dayed.cloud` |
| 비밀번호 | `Dayed!2026` |
| 인증 코드 | 필요 없음 (로그인만 하면 됨) |

> **실서버 전환 전까지**: `config.USE_MOCK = true` 라 위 계정으로 로그인하면
> 친구 20명 · 기록 64건이 이미 있는 상태로 들어감. 아무 이메일·8자 이상 비밀번호로도 들어감.
>
> **실서버 전환 후 반드시 할 일**: 위 계정을 실제로 만들고 친구·기록을 심어둘 것.
> 닫힌 친구망이라 **빈 계정으로 들어가면 앱이 텅 비어 보이고**, 그게 2.1/4.2 반려 사유가 됨.

## 심사 노트 (Notes)

```
Dayed 는 하루에 한 장(사진 또는 글)만 남기고, 서로 수락한 친구끼리만
보는 비공개 일기 앱입니다.

■ 시연 계정
  demo@dayed.cloud / Dayed!2026
  친구와 기록이 미리 들어 있습니다.

■ 이용자 콘텐츠 관리 (Guideline 1.2)
  · 신고 — [친구] 탭에서 사람을 눌러 들어간 프로필의 우측 상단 ⋯ ,
           또는 각 기록 카드의 ⋯ → "신고하기"
           사유 6가지 중 선택 → 접수 후 차단까지 이어서 안내
  · 차단 — 같은 ⋯ → "OOO님 차단하기"
           차단하면 서로의 기록이 사라지고, 상대는 검색·친구요청이 불가합니다
  · 차단 해제 — [나] 탭 우상단 ⚙︎ → 차단한 사람
  · 문의처 — support@dayed.cloud (앱 내 이용약관·개인정보 처리방침에 표기)

■ 화면 구성
  하단 탭 두 개입니다 — [나] [친구].
  · 나   — 오늘 쓰기 → 달력. 설정은 우상단 ⚙︎
  · 친구 — 오늘 누가 남겼는지 → 받은 요청 → 내 친구 목록. 검색은 맨 위
  · 오늘 쓰기 — [나] 탭의 "무슨 일이 있었나요?" 줄, 또는 달력의 오늘 칸
  · 지난 날 채우기 — 달력의 빈 날을 누르면 그날로 작성됩니다

■ 계정 관리
  · 프로필 편집 — [나] 탭 ⚙︎ → "프로필 편집" (사진·닉네임)
  · 비밀번호 변경 — [나] 탭 ⚙︎ → "비밀번호 변경" (현재 비밀번호 확인 후)
  · 계정 삭제 (Guideline 5.1.1(v))
    [나] 탭 ⚙︎ → 맨 아래 "계정 삭제" (2단계 확인 후 즉시 삭제)

■ 약관·개인정보 처리방침
  가입 화면의 동의 줄에서 각각 눌러 전문을 볼 수 있고,
  [나] 탭 ⚙︎ → 이용약관 / 개인정보 처리방침 에서도 볼 수 있습니다.

■ 카메라·사진첩
  카메라는 그날의 사진을 찍을 때만, 사진첩은 고른 한 장만 읽습니다.
  위치·연락처·광고 식별자는 수집하지 않습니다.
```
